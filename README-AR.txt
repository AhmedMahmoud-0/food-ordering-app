إعادة تصميم الفوتر فقط — Food Ordering App

سبب التعديل:
المعاينة السابقة أظهرت أن HTML الخاص بروابط الفوتر ظهر، لكن تنسيقات الفوتر الجديدة لم تُطبّق؛ فظهر المحتوى في عمود واحد وعلى خلفية فاتحة. هذا الإصدار ينقل تنسيقات الفوتر إلى CSS Module مستورد مباشرة داخل مكوّن Footer، لعزلها عن تنسيقات الفوتر القديمة في globals.css.

طريقة التركيب:
1) فك ضغط الحزمة.
2) انسخ مجلد src الموجود بداخلها إلى مجلد المشروع الرئيسي.
3) اختر Merge / Replace عند السؤال.
4) أعد تشغيل خادم التطوير (أوقف npm run dev ثم شغّله من جديد).

الملفات:
- src/components/Footer/index.tsx
- src/components/Footer/Footer.module.css (ملف جديد)
- src/dictionaris/en.json
- src/dictionaris/ar.json
- src/types/translations.ts

التصميم:
- خلفية فحمية دافئة متوافقة مع ألوان المشروع.
- استخدام الأحمر الأساسي #c83b30، والعاجي #fffaf4، ولمسة الزيتوني #65734b.
- شريط دعوة واضح لاستكشاف القائمة.
- هوية المطعم ووصفه، وثلاث مجموعات روابط منظمة.
- فاصل سفلي وحقوق النشر.
- تصميم متجاوب ودعم RTL / LTR.

النطاق:
- إعادة تصميم الفوتر فقط.
- لا تغيير في الصفحة الرئيسية أو قسم Fresh From Our Oven أو Best Sellers.
- لا تغيير في Prisma أو قاعدة البيانات أو Server Actions أو ملفات البيئة.
- روابط About وContact وباقي الصفحات تظل كما هي.

بعد التركيب:
أوقف خادم التطوير ثم شغّله مجددًا، وافتح الصفحة الرئيسية وانزل لأسفل لمعاينة الفوتر. بعد ذلك نفّذ npm run build.
