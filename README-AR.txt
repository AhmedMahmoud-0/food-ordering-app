تعديل زر تغيير اللغة في هيدر الموبايل

المشكلة:
زر تغيير اللغة كان داخل القائمة الجانبية التي تفتح بزر الهامبورجر.

التعديل:
- نقل زر LanguageSwitcher إلى جانب زر الهامبورجر في الهيدر على الشاشات الأصغر من lg.
- إزالة نسخة زر اللغة من داخل القائمة الجانبية حتى لا يظهر مكررًا.
- الإبقاء على زر اللغة الموجود في نسخة الكمبيوتر كما هو داخل Header.
- لم يتم تعديل منطق تبديل اللغة أو الروابط أو CSS العام أو أي صفحات أخرى.

التركيب:
1. فك ضغط الملف.
2. انسخ مجلد src إلى مجلد المشروع الرئيسي.
3. اختر Merge / Replace عند الطلب.
4. شغّل npm run build.

الملف المستبدل:
