تحديث استقرار التنقل والسلة - Food Ordering App

محتويات الحزمة:
1) src/components/link/index.tsx
   إزالة آلية prefetch اليدوية المعتمدة على mouseover/mouseleave، وتعطيل
   prefetch افتراضيًا في روابط التطبيق المخصصة. يمكن لأي استخدام تمرير
   prefetch صراحة إذا احتاج ذلك لاحقًا.

2) src/components/header/cart-button.tsx
   بناء رابط السلة باستخدام اللغة الحالية مباشرة: /ar/cart أو /en/cart.

3) src/app/[locale]/_components/Hero.tsx
   بناء روابط Menu وAbout باستخدام اللغة الحالية مباشرة بدل الاعتماد على
   Middleware لإضافة اللغة.

4) src/components/Footer/index.tsx
   نسخة الفوتر المعاد تصميمه سابقًا، مع prefetch={false} لروابطه المباشرة.
   التعديل يحافظ على تصميم الفوتر والترجمات الحالية.

5) src/app/[locale]/cart/loading.tsx
   واجهة تحميل ظاهرة أثناء انتظار صفحة السلة.

6) src/app/[locale]/cart/error.tsx
   Error Boundary خاص بصفحة السلة، يعرض رسالة عربية أو إنجليزية وزر إعادة
   المحاولة، ويسجل الخطأ في Console. هذا لا يخفي الخطأ البرمجي؛ بل يمنع
   ظهور مساحة فارغة إذا وقع استثناء أثناء عرض صفحة السلة.

طريقة التركيب:
- أوقف npm run dev إن كان يعمل.
- فك ضغط الملف.
- انسخ مجلد src إلى مجلد المشروع الرئيسي.
- اختر Merge/Replace عند الطلب.
- لا تستبدل ملفات أخرى خارج المسارات المذكورة أعلاه.

الاختبارات بعد التركيب:
1) npm run lint
2) npx next typegen
3) npx tsc --noEmit
4) npm run build

ثم اختبر على نسخة Preview من Vercel قبل اعتمادها على Production:
- فتح الصفحة الرئيسية ثم الضغط على أيقونة السلة.
- التنقل Menu -> Cart -> Home -> Cart عدة مرات.
- التجربة في العربية والإنجليزية.
- تسجيل الدخول والخروج وتجربة روابط Profile وOrders.
- إبقاء تبويب الموقع مفتوحًا لفترة ثم العودة وتجربة التنقل.

ملاحظات مهمة:
- لم يتم تعديل Redux أو localStorage أو Prisma أو قاعدة البيانات أو Middleware.
- تعطيل prefetch يؤخر تحميل بيانات الصفحة إلى وقت الضغط على الرابط، وقد يجعل
  الانتقال أبطأ قليلًا، لكنه يتجنب إعادة استخدام استجابات prefetch القديمة.
- لا يمكن اعتبار المشكلة محلولة نهائيًا قبل تجربة نسخة Preview ومراقبة
  Console وNetwork إذا تكرر العطل.
